## 全局安全规则（详细见 `SAFETY.md`）

1. **任何探针都不写 NOR 的裸扇区、不写固件分区表、不擦块**；所有“改固件”只发生在**副本文件**上。
2. 真机侧只允许两类写入：① 刷入完整签名容器（仅在你明确同意时）；② 卡上写普通文件（如 `PICCON01.NP3`）。
3. 探针脚本必须在 README 的“写入目标”里列全路径；没有列出的写入视为 bug。
4. 探针失败时应回滚到原厂文件/原卡，不留下半写状态。

## 每个子目录的内容约定

- 代理复核产出的 `PROBE_SAFETY.md`（重新跑过探针后的写目标审计）。
